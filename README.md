# もじ あそび (moji-asobi)
カタカナを、一文字ずつ、書き順のとおりに、指でなぞって書く遊び。
- 画面：ます目に、うすい色の見本の文字。緑の●（画の番号つき）から、線の終わりまでなぞる。1画書けると色がつき、つぎの画へ。ぜんぶ書けると、つぎの文字へ進む。
- 文字：カタカナ46文字（ア〜ン）。書き順のデータは自作（`KANA`、100×100 のます目、M/L/Q）。
- 支援者メニュー：行／文字／書けたあと（つぎの文字へ・同じ文字をもう一度）／手助け／くわしく。構成は、他のアプリ（かく あそび・きる あそび等）と同じ。
- 失敗の音・×なし（線が進まないだけ）。お祝いの強さは調整可。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。名前・記録は保存しない。カメラ・マイク不使用。
- 設計：docs/spec.md
