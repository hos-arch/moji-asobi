# もじ あそび 仕様（moji-asobi）（第3版）
他のアプリの順番（段階）には含めない、単独のアプリ。現場で使っている「書き順つきの文字表」と同じ使い方（書き順を見て、なぞる）を、画面でできるようにする。

## 0. 考え方
- 子どもに正解させるアプリではなく、子どもが自分から何度も書きたくなるアプリにする。
- 一文字ずつ。1画ずつ。書けたら、つぎへ進む。
- 失敗は静かに。線から離れても、反対の向きになぞっても、いやな音や×は出さない（線が進まないだけ）。

## 1. 画面
- ます目（十字の点線つき）に、見本の文字を、うすい灰色の太い線で出す。
- いま書く画：中心に細い点線、始まりに緑の●と画の番号、その先に向きの矢印、終わりに小さな点。
- ●に指を置き、終わりまでなぞると、線に色がつく（1画目 赤／2画目 青／3画目 だいだい／4画目 緑）。進むと小さな音。
- 線は、いま書いた所の先からだけ伸びる。書き始めは●の近くから。
- 1画書けたら、指を一度はなして、つぎの画の●から書く（はなさずに続けても、つぎの画は進まない）。
- ぜんぶの画が書けると、星と音（お祝いの強さは支援者が選ぶ）。そのあと、つぎの文字になる。
- しばらく待つと、書く向きを示す点が、始まりから終わりへ動く（手助け 大きい＝3秒／ふつう＝7秒／小さい＝出ない）。
- 画面に出る文字は、見本の文字と、画の番号だけ。説明の文は出さない。

## 2. 文字
- カタカナ46文字（ア〜ン）と、ひらがな46文字（あ〜ん）。行：ア（あ）・カ・サ・タ・ナ・ハ・マ・ヤ・ラ・ワ。
- はじめはひらがな（2026-11-10 決定）。支援者メニューの「文字の種類」で、ひらがな／カタカナを切りかえる（切りかえると、その種類の「あ」「ア」から始まる）。
- ひらがなの書き順のデータは、KanjiVG（© Ulrich Apel、CC BY-SA 3.0）をもとに、座標を変換して使う（自作の形は不自然だったため、第3版で入れ替えた）。画数と書き順は、現場の「ひらがな表」と同じ（き＝4画、さ＝3画、そ＝1画 など）。出どころは、README と、支援者用の説明に書く。
- 順番：ア行から、行の中を順に。行の終わりまで書くと、つぎの行へ。ンのあとは、アに戻る。
- 書き順のデータは自作。100×100 のます目に、画ごとに、始点・直線・曲線で書く（`KANA`）。
- 文字の形は、なぞりやすさを優先した見本。とめ・はね・はらいの細かい形は表さない（紙に書くときに、大人が教える）。

## 3. 支援者メニュー（他のアプリと同じ構成）
- 文字の種類（ひらがな（初期値）／カタカナ）
- 行（10個。種類によって、ア行／あ行 の表示が変わる）
- この行：文字（その行の文字）、書けたあと（つぎの文字へ（初期値）／同じ文字をもう一度）、この文字をはじめから、つぎの文字にする
- みんな共通：手助け（大きい＝線から離れても書ける・向きの点が早く出る／ふつう／小さい＝線の上を正確に・向きの点なし）
- くわしく：触れ方、見た目、お祝いの強さ（なし／控えめ（初期値）／ふつう／派手）、音、説明をもう一度
- もとにもどす／とじる。画面の下に「とめる」「おしまい」

## 3.5 画面の向き
- 画面の向きや大きさが変わったら、同じ文字のまま、書いた所を残して、ます目を置き直す。
- 第2版までは、向きを変えると内部でエラーが起き、位置が戻らなかった（第3版で修正。きる あそび・はめ あそびにも同じ不具合があり、同時に修正）。

## 4. 約束（他のアプリと同じ）
- 点滅なし。音はやわらかく、音量は支援者が調節。
- 名前・記録・声・顔を保存しない。カメラ・マイクは使わない。治療効果をうたわない。

## 5. 未決
- 数字を加えるか。
- 濁音・半濁音・小さい文字（ッ・ャなど）を加えるか。
- 見本の文字の形：現場で見て、直したい文字があれば直す。
- 見本なしで書く段階（なぞり→見て書く）を作るか。

## 6. 確認（2026-11-10）
- 第3版：ひらがなを入れ替え、46文字の形を画像で目視確認。縦→横→縦と向きを変えても、エラーなし、書いた所が残り、ます目が中央に戻る（Playwright）。実機は未確認。
- 第2版：ひらがな46文字を追加。Playwrightで、カタカナ46・ひらがな46の全文字を書き順どおりになぞれる（iPad横・iPhone縦ほか）。メニューの「文字の種類」と、行ボタンの切りかえ、もとにもどす。
- Playwright：46文字すべてを、書き順どおりになぞると書ける（iPad横）。iPad縦・iPhone縦横・SEでも書ける。反対の向きになぞっても進まない。指をはなさずに続けても、つぎの画は進まない。書けたあと、自動でつぎの文字になる。メニューの行・文字・もとにもどす。エラーなし。
- 46文字の形と書き順は、画像で目視確認。実機（iPhone・iPad）は未確認。
